# Imane Biya — Économie & Société

Blog personnel d'Imane Biya, étudiante en économie : analyses et décryptages de
l'actualité économique et sociale.

Site statique (un seul fichier `index.html`), sans dépendance, prêt à être
hébergé sur Netlify, Cloudflare Pages, Vercel ou GitHub Pages.

## Aperçu local
Ouvre simplement `index.html` dans un navigateur.

## Déploiement
Glisser-déposer `index.html` sur Netlify, ou activer GitHub Pages sur la
branche `main`.
